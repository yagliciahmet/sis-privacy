# SiS privacy policy

The public privacy policy of the SiS Android app, published with GitHub Pages
at https://yagliciahmet.github.io/sis-privacy/. Google Play's store listing and
the app's Settings screen both link to that address.

`index.html` is the whole site. It holds the policy in Turkish and English;
keep both halves saying the same thing and update the effective date whenever
the content changes.
